# المُدقِّق — Al-Mudaqiq

تطبيق ويب من ملف واحد لتدقيق النصوص العربية: إملائي، نحوي، تشكيل كامل، إعادة صياغة، استخراج الحوار، وتحويل الفصحى إلى ٢١ لهجة عربية — مدعوم بواجهة Anthropic API مباشرة من المتصفح.

A single-file web app for Arabic proofreading (spelling, grammar, full tashkeel, rewriting, dialogue extraction, and dialect conversion), powered by the Anthropic API directly from the browser.

## التشغيل / Run

افتح `index.html` في المتصفح (أو انشره على أي استضافة ثابتة)، ثم أدخل مفتاح Anthropic API من ⚙ الإعدادات — يُحفظ في متصفحك فقط.

Open `index.html` in a browser (or host it anywhere static), then paste your Anthropic API key in ⚙ Settings — it is stored only in your browser.

## التصميم / Design

واجهة «شفق منتصف الليل» — لغة بصرية حديثة مستوحاة من مواقع Stripe وLinear وVercel، بوضعين داكن (أساسي) وفاتح:

- **الهوية**: أرضية كحلية عميقة تتنفس خلفها توهّجات شفقية (بنفسجي ← وردي ← سماوي)، وسطوح زجاجية بحدود متدرجة، مع تدرّج لوني مميز للأزرار الرئيسية وعنوان الترويسة.
- **الخطوط**: Alexandria للعناوين، IBM Plex Sans Arabic للواجهة، وNoto Naskh Arabic لنص المحرر والنتائج.
- **الترويسة**: عنوان بتدرّج لوني مقصوص على النص، وتوهّجات شفقية متحركة ببطء (تحترم `prefers-reduced-motion`)، وشبكة منقّطة خافتة — CSS خالص بلا صور.
- **المكوّنات**: بطاقات أوضاع بحدود متدرجة عند الاختيار، أزرار مقسّمة بأسلوب iOS، شريط تنقّل سفلي عائم بزجاجية ضبابية، وألوان دلالة (وردي للخطأ، أخضر للتصويب، كهرماني للتنبيه) منفصلة عن اللون المميز.

## ميزات الواجهة / UX features

- **مظهر داكن كامل** يتبع تفضيل النظام مع زر تبديل يُحفظ اختياره.
- **حفظ تلقائي للمسودة**: نصك يبقى بعد إغلاق الصفحة ويُسترجع عند العودة.
- **اختصار لوحة المفاتيح**: Ctrl+Enter (أو ⌘+Enter) يبدأ التحقيق من المحرر.
- **زر مسح بتأكيد خفيف** يمنع الحذف بالخطأ، وزر **إظهار/إخفاء مفتاح API**.
- **إتاحة**: تسميات ARIA، حالات `aria-pressed`، مناطق إعلان حية للنتائج والأخطاء، حلقات تركيز واضحة، واحترام `prefers-reduced-motion`.
- **تفاصيل**: شريط علوي لاصق بخلفية ضبابية، أرقام جدولية للعدادات، تمرير تلقائي إلى النتيجة، ودعم المساحات الآمنة لهواتف iOS.
