# المُدقِّق — Al-Mudaqiq

تطبيق ويب من ملف واحد لتدقيق النصوص العربية: إملائي، نحوي، تشكيل كامل، إعادة صياغة، استخراج الحوار، وتحويل الفصحى إلى ٢١ لهجة عربية — مدعوم بواجهة Anthropic API مباشرة من المتصفح.

A single-file web app for Arabic proofreading (spelling, grammar, full tashkeel, rewriting, dialogue extraction, and dialect conversion), powered by the Anthropic API directly from the browser.

## التشغيل / Run

افتح `index.html` في المتصفح (أو انشره على أي استضافة ثابتة)، ثم أدخل مفتاح Anthropic API من ⚙ الإعدادات — يُحفظ في متصفحك فقط.

Open `index.html` in a browser (or host it anywhere static), then paste your Anthropic API key in ⚙ Settings — it is stored only in your browser.

## التصميم / Design

لغة بصرية اسمها **«المِحراب»**، مستوحاة من لوحات العِبَر الإسلامية: ورقٌ دافئ، أقواسٌ محرابية، وردي باهت وذهب.

- **الهوية**: أرضية حجرية كريمية بتدرّجٍ خفيف ووهجُ فوانيس في الزوايا وعروقُ رخام شفيفة — CSS خالص بلا صور.
- **الأقواس المحرابية**: البطاقات الرئيسية (الترويسة، المحرر، النتيجة، الإعدادات، الألواح) تُتوَّج بقوسٍ محرابي عبر رموز `--arch-*`، بإطارٍ مزدوج فاتح وحدٍّ ذهبي.
- **الشارات المرقّمة**: بطاقات الأخطاء وبطاقات الدليل تحمل شارةً دائرية وردية مرقّمة تلقائياً بعدّادات CSS، تتوّج أعلى البطاقة — كترقيم اللوحة المرجعية.
- **لوحة القاعدة**: `rule-tag` قرصٌ ورديٌّ بنصٍّ أبيض، نظيرُ لوحة «العبرة» في اللوحة.
- **الخطوط**: Cairo للعناوين، IBM Plex Sans Arabic للواجهة، وAmiri (مع Noto Naskh Arabic بديلاً) لنص المحرر والنتائج.
- **الأيقونات**: أيقونات SVG خطّية موحّدة في الشريطين العلوي والسفلي وفي بطاقات الأوضاع الست، بدل الرموز التعبيرية.
- **الحلي**: فواصل ذهبية بمعيَّنٍ أوسط (❖)، وزخرفةُ محرابٍ شفيفة خلف العنوان، وشريط تنقّل سفلي بخيطٍ ذهبي وزجاجيةٍ ضبابية.

## ميزات الواجهة / UX features

- **وضعان فاتح وداكن** يتبعان تفضيل النظام عبر `prefers-color-scheme` — «مِحرابٌ بعد المغرب» بأرضية بنّية دافئة.
- **تباين مطابق لـWCAG AA**: كل أزواج النص/الخلفية تبلغ 4.5:1 فأعلى في الوضعين.
- **أهداف لمس ≥ 44px** لكل زر، مع حالات ضغط ومرور واضحة ومدد انتقال 220ms.
- **حلقات تركيز مرئية** لمستخدمي لوحة المفاتيح على كل عنصر تفاعلي.
- **احترام `prefers-reduced-motion`** وتعطيل النبض والانتقالات عند طلبه.
- **دعم المساحات الآمنة** لهواتف iOS في الشريطين العلوي والسفلي.
- **استجابة كاملة**: شبكة الأوضاع تتكيّف من عمودين على الجوال إلى ثلاثة فأكثر على الشاشات الأوسع، بلا تمرير أفقي حتى عرض 320px.
